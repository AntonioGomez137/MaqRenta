# MaqRenta

Sitio de demostración (MVP) de renta de maquinaria pesada. Datos ficticios. Sin backend.

## Cómo correrlo

1. Instala [Node.js LTS](https://nodejs.org/) (incluye `npm`).
2. Abre una terminal en esta carpeta:

```bash
cd "C:\Users\CMGOLFO-30\Documents\Toño\Renta\maqrenta"
npm install
npm run dev
```

3. Abre [http://localhost:3000](http://localhost:3000).

Otros comandos:

```bash
npm run lint
npm run build
npm start
```

`npm start` sirve la versión de producción después de `npm run build`.
